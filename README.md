# Passion – управление диктовкой наклоном головы

Passion позволяет запускать и останавливать запись речи в Handy с помощью наклона головы влево или вправо перед веб-камерой. После завершения записи полученная транскрипция может автоматически отправляться в LLM через OpenRouter либо напрямую в приложение Claude Desktop.

## Как это работает

### Отслеживание положения головы

Приложение использует MediaPipe Face Landmarker для определения положения лица на изображении.

Для оценки наклона головы используются координаты левого и правого глаза. По линии между глазами вычисляется угол поворота головы относительно горизонтали.

### Базовое положение

После запуска система запоминает естественное положение головы пользователя и поддерживает динамическую базовую линию.

Пока жест не выполняется, базовое положение плавно обновляется, компенсируя небольшие изменения позы.

### Распознавание жеста

Жест состоит из двух этапов:

1. Пользователь наклоняет голову влево или вправо примерно на 15°.
2. После этого возвращает голову в почти нейтральное положение.

Только последовательность «наклон → возврат» считается завершённым жестом.

Такой подход помогает избежать случайных срабатываний от небольших движений головы.

### Кулдаун

После каждого срабатывания действует пауза 1.2 секунды, во время которой новые жесты игнорируются.

## Управление записью

Каждый распознанный наклон переключает состояние диктовки Handy:

* если запись не идёт — запускается запись;
* если запись уже идёт — запись завершается.

## Получение текста

После остановки записи Handy автоматически помещает транскрипцию в буфер обмена.

Программа ожидает появления нового текста в течение 45 секунд.

## Режимы ответа

### API Mode

Текст отправляется в выбранный LLM-провайдер:

* OpenRouter
* OpenAI
* Anthropic
* DeepSeek

Одновременно используются две модели:

* быстрая модель для мгновенного ответа;
* более мощная модель для точного ответа.

### Claude Desktop Mode (macOS)

Вместо API вопрос автоматически отправляется в приложение Claude Desktop.

Программа переводит фокус на Claude, ждёт завершения диктовки и отправляет сообщение без участия пользователя.

## Управление

| Действие                       | Результат           |
| ------------------------------ | ------------------- |
| Наклон головы влево или вправо | Старт / стоп записи |
| q                              | Выход               |
| Ctrl+C                         | Выход               |

## Визуальная индикация

В окне камеры отображаются:

* линия между глазами;
* текущий угол наклона;
* состояние WATCHING или ARMED.

## Настраиваемые параметры

| Параметр              | Значение по умолчанию | Назначение                             |
| --------------------- | --------------------- | -------------------------------------- |
| TILT_ON_DEG           | 15                    | Угол наклона для взведения жеста       |
| TILT_OFF_DEG          | 7                     | Угол возврата для фиксации жеста       |
| BASELINE_ALPHA        | 0.05                  | Скорость обновления базового положения |
| COOLDOWN_SEC          | 1.2                   | Минимальная пауза между жестами        |
| CLIPBOARD_TIMEOUT_SEC | 45                    | Максимальное ожидание транскрипции     |

## Ограничения

Система не использует отдельную модель распознавания жестов.

Решение основано исключительно на измерении угла линии глаз относительно базового положения головы.

Ложные срабатывания возможны при:

* сильном вращении головы;
* частичном перекрытии лица;
* потере одного из глаз в кадре;
* плохом освещении;
* резких движениях камеры.

Проект ориентирован на максимально быстрый и лёгкий способ управления диктовкой без использования дополнительных устройств ввода.
