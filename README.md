# Passion – управление диктовкой кивком головы

Распознаёт сильный кивок головой через веб-камеру, переключает запись в приложении Handy и отправляет полученную транскрипцию в LLM через OpenRouter.

---

## Как работает

### 1. Отслеживание лица

Используется **MediaPipe Face Landmarker**, который определяет 468 ключевых точек лица. Для отслеживания положения головы используется кончик носа (индекс `1`).

### 2. Сглаживание движения

Вертикальная координата носа (`Y`) сглаживается скользящим средним по последним трём кадрам для уменьшения шума.

### 3. Базовая линия

Система поддерживает динамическую базовую линию положения головы (**baseline**). Пока кивок не начат, baseline плавно обновляется с коэффициентом `0.05`.

### 4. Детектирование кивка

Логика работает как конечный автомат:

#### Переход в состояние ARMED

Если голова опускается вниз более чем на **10%** относительно baseline:

```text
y > baseline × 1.10
```

система переходит в состояние `ARMED`.

#### Фиксация кивка

Если после этого голова поднимается обратно минимум на **6%**:

```text
y < armed_position × 0.94
```

кивок считается завершённым и выполняется действие.

#### Защита от повторных срабатываний

После каждого кивка действует кулдаун:

```text
1.2 секунды
```

---

### 5. Управление записью

При обнаружении кивка выполняется команда:

```bash
Handy --toggle-transcription
```

Она запускает или останавливает запись речи в Handy.

---

### 6. Получение транскрипции

После остановки записи программа ожидает изменения буфера обмена.

Handy автоматически копирует полученную транскрипцию в clipboard. Максимальное время ожидания:

```text
45 секунд
```

---

### 7. Отправка в LLM

Полученный текст отправляется в OpenRouter двумя параллельными запросами:

* **Gemini Flash** — быстрый ответ
* **Claude Opus 3** — более качественный и подробный ответ

---

### 8. Вывод результатов

Ответы обеих моделей выводятся в консоль.

## Установка

### 1. Установка зависимостей Python

```bash
pip install mediapipe opencv-python
```

### 2. Установка Handy (macOS)

Через Homebrew:

```bash
brew install --cask handy
```

Либо скачайте приложение вручную с сайта Handy.

Приложение работает полностью локально и не требует облачных сервисов.

---

### 3. Настройка OpenRouter

Зарегистрируйтесь на OpenRouter и создайте API-ключ.

Откройте `main.py` и укажите ключ:

```python
OPENROUTER_API_KEY = "sk-or-v1-..."
```

Если ключ не указан:

* управление Handy продолжит работать;
* ответы LLM будут отключены.

---

### 4. Модель MediaPipe

При первом запуске скрипт автоматически скачивает файл:

```text
face_landmarker.task
```

Если загрузка не произошла автоматически:

```bash
curl -O https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/latest/face_landmarker.task
```

## Интерфейс

Во время работы отображаются:

* зелёная линия — текущий baseline;
* красная точка — положение носа;
* статус системы: `WATCHING` или `ARMED`.

## Настраиваемые параметры

| Параметр                | Значение | Назначение                         |
| ----------------------- | -------- | ---------------------------------- |
| `DROP_RATIO`            | `0.10`   | Порог опускания головы             |
| `RETURN_RATIO`          | `0.06`   | Порог возврата головы              |
| `BASELINE_ALPHA`        | `0.05`   | Скорость обновления baseline       |
| `COOLDOWN_SEC`          | `1.2`    | Минимальный интервал между кивками |
| `CLIPBOARD_TIMEOUT_SEC` | `45`     | Максимальное ожидание транскрипции |

## Ограничения

Детектор кивка основан исключительно на вертикальном смещении кончика носа и не использует отдельную модель классификации жестов.

Возможны ложные срабатывания при:

* сильном повороте головы;
* резких движениях камеры;
* частичном выходе лица из кадра;
* плохом освещении.

Проект рассчитан на простое и быстрое управление диктовкой без использования специализированных моделей распознавания жестов.
