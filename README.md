# Passion — управление диктовкой наклоном головы

Passion запускает и останавливает запись речи в [Handy](https://handy.computer) наклоном головы влево или вправо перед веб-камерой. После записи транскрипция отправляется в LLM через выбранного провайдера либо напрямую в приложение Claude Desktop.

## Установка

```bash
pip install mediapipe opencv-python
```

Дополнительно понадобятся:

- Python 3.10+
- [Handy](https://handy.computer), настроенный на копирование транскрипции в буфер обмена
- веб-камера
- для API-режима — ключ одного из поддерживаемых провайдеров
- для Claude Desktop-режима — macOS, [приложение Claude](https://claude.ai/download) и разрешение Accessibility для терминала (System Settings → Privacy & Security → Accessibility)

Модель MediaPipe (`face_landmarker.task`, ~3.7 МБ) скачивается автоматически при первом запуске.

## Запуск

```bash
python3 app.py          # запуск (при первом старте — мастер настройки)
python3 app.py setup    # перенастройка: режим, провайдер, ключ
python3 app.py models   # смена моделей для быстрого и точного ответа
```

Мастер спрашивает режим ответа (API или Claude Desktop — второй только на macOS), провайдера и API-ключ. Всё сохраняется в `config.json` рядом со скриптом, поэтому следующие запуски стартуют сразу.

## Как это работает

### Отслеживание положения головы

Приложение использует MediaPipe Face Landmarker для определения положения лица. По координатам левого и правого глаза вычисляется угол линии между глазами относительно горизонтали — это и есть наклон головы.

### Базовое положение

После запуска система запоминает естественное положение головы и поддерживает динамическую базовую линию. Пока жест не выполняется, базовое положение плавно обновляется, компенсируя небольшие изменения позы.

### Распознавание жеста

Жест состоит из двух этапов:

1. Наклон головы влево или вправо примерно на 15°.
2. Возврат головы в почти нейтральное положение.

Только последовательность «наклон → возврат» считается завершённым жестом — это помогает избежать случайных срабатываний от мелких движений.

### Кулдаун

После каждого срабатывания действует пауза 1.2 секунды, во время которой новые жесты игнорируются.

## Управление записью

Каждый распознанный наклон переключает состояние диктовки Handy:

- если запись не идёт — запускается запись;
- если запись уже идёт — запись завершается.

## Получение текста

После остановки записи Handy автоматически помещает транскрипцию в буфер обмена. Программа ожидает появления нового текста в течение 45 секунд.

## Режимы ответа

### API Mode

Текст отправляется выбранному LLM-провайдеру. Одновременно работают две модели: быстрая выдаёт ответ мгновенно (стримится в консоль), а более точная досчитывается следом.

| Провайдер  | Быстрая модель (по умолчанию) | Точная модель (по умолчанию) |
|------------|-------------------------------|------------------------------|
| OpenRouter | `google/gemini-2.5-flash`     | `anthropic/claude-opus-4.8`  |
| OpenAI     | `gpt-5-mini`                  | `gpt-5`                      |
| Anthropic  | `claude-haiku-4-5`            | `claude-opus-4-8`            |
| DeepSeek   | `deepseek-chat`               | `deepseek-reasoner`          |

Любой слаг модели провайдера можно задать через `python3 app.py models`.

### Claude Desktop Mode (macOS)

Вместо API вопрос отправляется в приложение Claude Desktop. Программа переводит фокус на Claude, ждёт завершения диктовки и отправляет сообщение без участия пользователя.

## Управление

| Действие                       | Результат           |
|--------------------------------|---------------------|
| Наклон головы влево или вправо | Старт / стоп записи |
| `q`                            | Выход               |
| `Ctrl+C`                       | Выход               |

## Визуальная индикация

В окне камеры отображаются:

- линия между глазами;
- текущий угол наклона;
- состояние WATCHING или ARMED.

## Настраиваемые параметры

Константы в начале `app.py`:

| Параметр                | По умолчанию | Назначение                              |
|-------------------------|--------------|-----------------------------------------|
| `TILT_ON_DEG`           | 15           | Угол наклона для взведения жеста         |
| `TILT_OFF_DEG`          | 7            | Угол возврата для срабатывания жеста     |
| `BASELINE_ALPHA`        | 0.05         | Скорость обновления базового положения   |
| `COOLDOWN_SEC`          | 1.2          | Минимальная пауза между жестами          |
| `CLIPBOARD_TIMEOUT_SEC` | 45           | Максимальное ожидание транскрипции       |
| `SHOW_WINDOW`           | True         | Показывать окно камеры с текущим наклоном |
| `NEW_CHAT_PER_QUERY`    | False        | Desktop-режим: новый чат на каждый вопрос |

Если жест срабатывает слишком легко — увеличь `TILT_ON_DEG`; если трудно — уменьши. Текущий угол наклона виден в окне камеры, по нему удобно подобрать порог.

## Ограничения

Система не использует отдельную модель распознавания жестов — решение основано исключительно на измерении угла линии глаз относительно базового положения головы.

Ложные срабатывания возможны при:

- сильном вращении головы;
- частичном перекрытии лица;
- потере одного из глаз в кадре;
- плохом освещении;
- резких движениях камеры.

## Заметки

- `config.json` содержит API-ключ в открытом виде — он в `.gitignore`, держи его там.
- Новый жест отменяет предыдущий незавершённый запрос, поэтому вопросы можно задавать подряд.
- В этой сборке нет детекта системного звука.
